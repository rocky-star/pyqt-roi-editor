PyQt ROI Editor 说明
====================

*其他语言：*\ `English <README.rst>`__

简介
----

PyQt ROI Editor 是一款在图像上绘制感兴趣区域（ROI）的小型桌面程序。\
它用 Python 与 PySide6 编写，把一份文档保存在单个\ ``.rsroi``\ 文件里。

一份文档包含一个或多个\ *底图*，即形状绘制在其上的图像，以及任意数量的\
*形状*，每个形状是一条线段或一个多边形，标注当前底图上的一块区域。\
界面跟随系统语言，并随程序附带一份简体中文翻译。

安装与使用
----------

本编辑器需要 Python 3.12 或更高版本，唯一依赖为 PySide6 6.11.2 或更高版本。\
从仓库安装本发行版，然后运行它提供的命令：

.. code-block:: console

   $ pip install git+https://github.com/rocky-star/pyqt-roi-editor.git
   $ pyqt-roi-editor

编辑区位于两个停靠面板之间：底图列表，以及列出每个顶点及其 X、Y 坐标的形状树。\
一次典型的操作流程是：**文件 > 新建**：新建一份空文档；\
**底图 > 添加底图...**：导入一张用于绘制的图像，\
底图列表可在含有多张图像的文档之间切换；\
**形状 > 添加形状 > 线段**\ （或\ **多边形**\ ）：开始绘制一个形状；\
**形状 > 形状属性...**：重命名选中的形状；\
**文件 > 保存**：把整份文档写入一个\ ``.rsroi``\ 文件。

绘制
  形状可从\ *形状*\ 菜单或画布上用次要按钮打开的菜单开始绘制，其顶点既可在视图中单击，也可\
  录入浮动面板。面板同样接受\ ``10, 20``、``10 20``、``(10, 20)``\ 和\
  ``[10, 20]``，按数字键或减号即可打开；按 Enter 结束多边形，按 Esc 取消正在\
  绘制的形状。

编辑
  拖动形状或它的某个控制柄即可移动，顶点通过\ *顶点*\ 菜单增删。除非形状属性\
  允许顶点超出底图，顶点会保持在底图之内：录入这样的坐标会自动打开该选项。

导航
  *工具箱*\ 菜单决定鼠标主要按钮的用途：选择并移动形状、移动视图或缩放视图。无论\
  当前是哪种工具，第三按钮都可移动视图；缩放工具下用次要按钮框出一块区域即可\
  让视图填满该区域；状态栏的缩放框可选择预设、输入百分比（如\ ``149%``），或适应\
  宽度、适应窗口。

转储
  *形状 > 转储形状*\ 把形状的顶点写成紧缩列表\
  ``[[10, 10], [20, 20]]``，或写成每行一项的 YAML 块序列，并可将任一形式复制\
  到剪贴板。
